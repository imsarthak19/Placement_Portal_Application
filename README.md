# Placement_Portal_Application
A comprehensive Placement Portal connecting Institutes, Companies, and Students. Manages recruitment drives, application tracking, and approvals. Built with a Flask REST API and VueJS frontend, utilizing Redis &amp; Celery for asynchronous background jobs like daily reminders, CSV exports, and automated monthly reporting.
